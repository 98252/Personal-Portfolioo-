## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/98252/Personal-Portfolioo-.git
   cd Personal-Portfolioo-
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run development server**:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Build for Production

```bash
npm run build
npm start
```
